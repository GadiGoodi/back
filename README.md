## 💻 프로젝트 소개
실시간 공동 작업이 가능한 IDE 및 코드 리뷰 커뮤니티 웹 서비스

## 🗓 개발 기간
2024.10 ~ 2025.1

## ⚙ Environment
### 💻 Development
- Language: Java 17 (JDK 17)
- Framework: Spring Boot 3.3.5
- Build Tool: Gradle 8.x
- Database: MariaDB, MongoDB, Redis
- IDE: IntelliJ IDEA / Eclipse
- Database Access: Spring Data JPA (QueryDSL 적용)

### ☁️ Infrastructure
- 서버: AWS EC2 (Ubuntu)
- Containerization: Docker, Docker Compose
- Deployment & Automation: Ansible
- CI/CD: GitHub Actions

### 📚 Tech Stack
- 인증/보안: Spring Security, OAuth2 Client, JWT
- Messaging: WebSocket
- 메일 서비스: Spring Mail
- 캐싱: Redis
- 데이터베이스: MariaDB, MongoDB
